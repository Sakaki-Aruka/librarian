# librarian

書籍情報を管理するCLIツール。[Clikt](https://ajalt.github.io/clikt/) 製のサブコマンド構成で、SQLite上の書籍データベースに対して追加・削除・一覧・初期化を行う。  
主に日本国内での利用を想定しており、JAN コードをオプションとして受け付けることができる。

## ビルド・実行

開発中にコンパイルしてそのまま実行する場合:

```
mvn compile
mvn exec:java -Dexec.args="<subcommand> [options...]"
```

実行可能jar（依存関係を全て含んだfat jar）を作る場合:

```
mvn package
java -jar target/librarian-1.0-SNAPSHOT.jar <subcommand> [options...]
```

## コマンド一覧

### 共通オプション（全サブコマンド）

| オプション | 説明 |
|---|---|
| `--db <path>` | データベースファイルのパス。省略時は `~/.librarian/books.db` |

(自動補完よりコマンドラインで明示指定した値が常に優先される)

- `add` / `delete` / `list`: 指定したパスにDBが存在しない場合はエラーで中断する
- `init`: 指定したパスに既にDBが存在する場合はエラーで中断する（上書きしない）

### init

データベースを新規作成する。

```
librarian init [--db <path>]
```

### add

書籍を1件登録する。   
複数冊を続けて登録できるインタラクティブモード（`-I`/`--interactive`）がある)

| オプション | 説明 |
|---|---|
| `--author` | 著者 |
| `--title` | タイトル（下記の補完で解決できない場合は必須） |
| `--price` | 価格 |
| `--publisher` | 出版社 |
| `--genre` | ジャンル |
| `--memo` | メモ |
| `--isbn` | ISBN |
| `--jancode` | 書籍JANコード（2段目） |
| `--code-set` | 本の2段バーコードを上段(ISBN)→下段(書籍JANコード)の順に連続スキャンして連結した26桁の文字列。前半13桁をISBN、後半13桁を書籍JANコードとして扱う |
| `--dry-run` | 実際には登録せず、登録される内容のプレビューのみ表示する |
| `-I`, `--interactive` | 登録後（値が指定されていれば）、続けて `add` をインタラクティブに実行できるモードに入る |
| `--mode-isbn`, `--mode-jancode`, `--mode-code-set`, `--mode-title` | インタラクティブモードで、それぞれ ISBN／書籍JANコード／2段バーコード連結文字列／タイトルだけを入力して登録できる専用モードに直接入る（`-I`と併用） |

補完ルール:

- `--jancode` が指定された場合、チェックデジットが不正なら「JANコードが不正です。正しく入力してください。」と表示して中断する。有効な場合は `price`（5桁の価格部）と `genre`（4桁のCコード、ゼロ埋め）を自動取得する
- `--isbn` が指定された場合、openBDから `author` / `title` / `publisher` / `price` を取得する。見つからない場合は警告を表示して指定されたフィールドのみで登録を続行する
- `--code-set` は26桁の数字でなければエラーで中断する。有効な場合、前半13桁・後半13桁を「そこに `--isbn`・`--jancode` が直接指定されたのと同じもの」として扱い、`--isbn`/`--jancode` が別途明示されていなければそちらを使う（明示指定があれば常にそちらが優先）
- 各フィールドの優先順位: **コマンドラインでの明示指定 > `--jancode`（`--code-set`由来を含む）由来 > openBD（`--isbn`・`--code-set`由来を含む）由来**
- 上記いずれからも `title` が決まらない場合はエラーで中断する

#### インタラクティブモード（`-I` / `--interactive`）

`add` にこのフラグを付けると、登録用のフィールド（`--author`等）が同時に指定されていればまずその1件を登録し、その後 `add>` プロンプトによる連続登録モードに入る。

- 入力は `add` より後ろの引数部分のみを、シェルと同じ感覚で書く（クオート・バックスラッシュエスケープ対応。トークン化には [JLine3](https://github.com/jline/jline3) の `DefaultParser` を使用）
  - 例: `--title "本 タイトル" --author "著者 A"`
- `h` または `help` だけを入力するとオプション一覧と抜け方を表示する
- `exit` でトップレベルのインタラクティブモードを終了する（終了時に登録待ちのエントリは必ず書き込まれる）
- `undo` で直前に登録待ち（まだDBに書き込んでいない）のエントリを取り消せる
- `--dry-run` は状態を変えないプレビューなのでモード内でも利用でき、指定すると登録待ちに追加せず内容だけ表示する
- `--db` / `-I` / `--interactive` / `--mode-*` はセッション開始時の設定に固定されるため、モード内では指定できない

**書き込みバッファ**: 頻繁なDBアクセスを避けるため、登録は最大3件まで内部バッファに溜めてからまとめて書き込む。バッファが3件を超えたら自動的に書き込み、`exit`/`EXIT` 時は件数に関わらず必ず書き込む。`undo` はこのバッファ内（＝未書き込み）のエントリにのみ効き、既に書き込み済みのものは取り消せない（`delete`コマンドを使うこと）。

#### フィールド専用モード（`--mode-isbn` / `--mode-jancode` / `--mode-code-set` / `--mode-title`）

インタラクティブモードの中に、1項目だけを連続入力するための専用モードがある。バーコードリーダーなどで値だけを連続してスキャン・入力する用途を想定している。

- トップレベルのインタラクティブモード中に `--mode-isbn` 等をそのまま入力すると、そのモードに切り替わる（別の専用モードにいる状態からの直接切り替えも可能）
- `add -I --mode-isbn` のように、最初から専用モードに直接入って起動することもできる
- モード中は、値（ISBN・書籍JANコード・2段バーコード連結文字列・タイトルのいずれか）だけを入力してEnterすれば、対応するオプションを指定したのと同じ内容で登録待ちに追加される（クオートは不要）
- `undo` はトップレベルと共通のバッファに対して働くので、モードを跨いでも直前のエントリを取り消せる
- `exit`（小文字）: 専用モードからトップレベルのインタラクティブモードに戻るだけ（セッションは終了しない）
- `EXIT`（大文字）: 現在のモードに関わらず、インタラクティブモードを経由せず**直接セッション全体を終了**する（登録待ちのエントリは必ず書き込まれる）

### list

条件に一致する書籍を一覧表示する。

| オプション | 意味 |
|---|---|
| `--author`, `--title`, `--publisher`, `--genre`, `--memo`, `--isbn`, `--jancode` | 完全一致検索 |
| `--kauthor`, `--ktitle`, `--kpublisher`, `--kgenre` | 部分一致（LIKE）検索 |

フィルタを何も指定しない場合は全件表示する。複数条件はすべてAND結合される。`--jancode` はチェックデジットが不正な場合エラーで中断する。

### delete

条件に一致する書籍を削除する。

| オプション | 意味 |
|---|---|
| `--author`, `--title`, `--publisher`, `--genre`, `--memo`, `--isbn`, `--jancode` | 完全一致検索 |
| `--kauthor`, `--ktitle`, `--kpublisher`, `--kgenre` | 部分一致（LIKE）検索 |
| `--dry-run` | 実際には削除せず、削除対象のプレビューのみ表示する |
| `--all` | フィルタを一切指定せずに全件削除する場合に必須のフラグ |

フィルタも `--all` も指定せずに実行するとヘルプを表示して処理を中断する（誤って全件削除するのを防ぐため）。`--jancode` はチェックデジットが不正な場合エラーで中断する。

## 使用例

```
# データベースを初期化
librarian init

# ISBNから情報を自動取得して登録
librarian add --isbn 9784873115658

# 書籍JANコードから価格・ジャンルを自動取得して登録
librarian add --title "サンプル本" --jancode 1920123016001

# 本の2段バーコードを上段→下段の順に連続スキャンして登録（ISBN・JANコード両方から自動補完）
librarian add --code-set 97848731156581920123016001

# 続けて複数冊登録する（インタラクティブモード）
librarian add -I
add> --title "1冊目"
add> --title "2冊目"
add> undo
add> exit

# バーコードリーダーでISBNだけを連続スキャンして続けて登録する（専用モードに直接起動）
librarian add -I --mode-isbn
add(ISBN)> 9784873115658
add(ISBN)> 9784480068255
add(ISBN)> EXIT

# 著者名の部分一致で検索
librarian list --kauthor 夏目

# ジャンルが完全一致する書籍を、実行せずプレビューだけ確認してから削除
librarian delete --genre SF --dry-run
librarian delete --genre SF

# 条件を付けずに全件削除
librarian delete --all
```
